# GitHub / Open Repository Campaign Leads

GitHub is a discovery surface, not a licence. A public repository, source file, PDF, ODT, JSON, Markdown file, or permissively licensed web application does **not** automatically mean that adventure/story content may be copied or adapted. Each repository and each campaign must be checked for an explicit content licence or creator permission before DungeonMasterOS templates any protected story material.

## Search policy for GitHub

For each useful repository:
1. read README and repository metadata
2. check detected licence and explicit `LICENSE`/content notices
3. distinguish software licence from campaign/content licence
4. list exact adventure files/titles
5. find creator-owned publication or permission when possible
6. only then promote a title to `licence-verified`

A missing licence means normal copyright applies. It does not mean `free to use because GitHub`.
