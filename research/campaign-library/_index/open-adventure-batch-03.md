## Research lesson

The Senator Bix repository is a useful example of why GitHub visibility alone is not enough. `Outpost Adventure` gains a reuse path because it can be independently tied to the openly licensed 2024 One Page Dungeon Contest; the other two adventure files remain licence-pending despite sitting in the same public GitHub repository.
