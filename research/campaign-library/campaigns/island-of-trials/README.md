# Island of Trials

Status: `researching`

## Executive summary

`Island of Trials` is a D&D 5e one-shot by Kreig Durham (`kreigd`). The creator describes it as an adventure for **four level-5 characters**, intended to run for **a few hours**. The party is whisked away to a mysterious island and confronted with an unknown test. It can be inserted into an existing campaign or used as the start of a new one.

The itch.io project page declares `Creative Commons Attribution v4.0 International` in its **Asset license** metadata. This is promising but is treated as provisional for full DungeonMasterOS adaptation until the actual PDF's own legal/attribution notice is inspected. Public availability and an itch metadata label are not substitutes for verifying the exact scope of rights inside the document.

## Why this matters for DMOS

Unlike many system-neutral one-page adventures, this source already states the exact player level and party size. If the PDF confirms that its full adventure content is CC BY 4.0, it is an excellent candidate for the built-in library because DungeonMasterOS can preserve the original 5e assumptions rather than inventing a conversion level.
