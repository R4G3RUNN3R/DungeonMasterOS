# Monkey Isle

Status: `researching`

Target source: **current 3rd Edition only**

## Executive summary

`Monkey Isle` is a lost-world adventure setting/module by J. D. Neal for the Basic Fantasy Role-Playing Game. The current 3rd Edition is a **60-page** island campaign environment intended for characters of **levels 4-6**. The official Basic Fantasy Project storefront describes a lush tropical island filled with ancient beasts, strange creatures and scattered ancient ruins, with numerous wilderness and dungeon adventure locations and an extensive new-monster section.

The current 3rd Edition is explicitly released under **Creative Commons Attribution-ShareAlike (CC BY-SA)** and is advertised as 100% OGL-free and 100% AI-free. The Basic Fantasy Project states that its electronic materials are distributed free through its own site and print books are sold at cost.

## Player-facing metadata verified for current edition

- Creator: J. D. Neal
- Publisher/project: Basic Fantasy Project
- Ruleset: Basic Fantasy RPG / old-school fantasy
- Recommended levels: **4-6**
- Format: wilderness-and-dungeon island adventure setting
- Length: **60 pages** in current Lulu listing
- Licence: **CC BY-SA** for current 3rd Edition
- Setting style: lost world / tropical island / prehistoric beasts / ancient ruins
- Reusable campaign form: island can support repeated visits rather than a single mandatory quest

## Critical edition rule

Older indexed copies of `Monkey Isle` are **2nd Edition / Release 21** and display OGL-era copyright/licensing. They are not to be treated as the current CC 3rd Edition source when DungeonMasterOS creates the built-in campaign template.

Do not silently combine old-edition room text with new-edition licence metadata. The current edition must be acquired and compared first.

## Why this is a major DMOS candidate

This is one of the strongest long-form finds so far because it provides:
- explicit level range
- large wilderness map
- multiple adventure locations
- actual dungeons
- a bespoke creature ecosystem
- replayable/revisitable setting rather than a single linear sequence
- community history of being adapted to other D&D-like systems

This will test whether DungeonMasterOS can maintain **persistent sandbox state** across repeated expeditions: discovered hexes, altered ruins, slain/relocated creatures, established safe bases, depleted treasure and returning factions/NPCs.
