# Monkey Isle - Sources and provenance

Accessed: 2026-08-17

## Current-edition source metadata

### Basic Fantasy Project / Lulu - Monkey Isle 3rd Edition
URL: https://www.lulu.com/shop/product-21809044.html

Supports current edition facts:
- author J. D. Neal
- Basic Fantasy adventure module
- tropical/lost-world island with ancient beasts and ruins
- island map
- numerous wilderness and dungeon adventure locations
- extensive section of new monsters
- recommended levels 4-6
- current 3rd Edition is CC BY-SA and explicitly OGL-free / AI-free
- 60 printed pages
- Basic Fantasy Project says its PDFs and broad range of additional material are distributed free from its own website, with print sold at cost

Authority: current publisher/project storefront metadata. Full digital source still needs official/current PDF acquisition.

## Older edition source - reference only, not current canon

Indexed copies identify:
- `Monkey Isle`, 2nd Edition / Release 21
- older OGL 1.0a copyright/licence structure
- older text describes a lost-world setting inhabited by prehistoric beasts and strange creatures and intended to be revisited

Examples are indexed on Scribd/AnyFlip and historical collections. These copies are **not** the source DungeonMasterOS should use for its public current-edition template. They may be used only for version comparison after the 3rd Edition is obtained.

## Community / review sources

### Matthew J. Constantine review (2023)
URL: https://matthewjconstantine.com/2023/03/03/tabletop-rpg-review-monkey-isle/

Supports reception/design comparison:
- reviewer sees Monkey Isle as a lost-world / Isle of Dread-style module with dinosaurs, apes and mysterious-island appeal
- reviewer considers it useful material to adapt into another old-school game

Edition caution: review predates/does not clearly identify the new CC 3rd Edition; use for community intelligence, not current source canon.

### Swords & Stitchery review/use report (2015)
URL: https://swordsandstitchery.blogspot.com/2015/11/reconsidering-osr-free-adventure.html

Supports historical table-use intelligence:
- describes wilderness crawl, ruins and prehistoric encounters
- values the island as reusable campaign territory and notes the usefulness of maps and home-base/farmland elements
- author reports personally using the adventure as part of a chain of lost islands / other campaigns

Edition caution: old edition. Do not promote old-edition details into current 3rd-edition canon until compared.

### RPGnet conversion discussion
URL: https://forum.rpg.net/index.php?threads/running-osr-modules-with-5e-what-to-watch-out-for.831433/

Supports:
- Monkey Isle is among Basic Fantasy modules DMs consider converting to D&D 5e
- conversion concerns include monster replacement, trap rebuilding and treasure scaling

This is community design intelligence, not source content.

### Goodreads reception
URL: https://www.goodreads.com/book/show/19678554-monkey-isle

Supports:

Edition caution: older publication/reviews.

### Actual-play podcast trace
Apple Podcasts listing for `Gilligan's Isle Of A.D.D.` includes episodes describing a Basic Fantasy Monkey Isle dungeon crawl embedded into an Isle of Dread campaign. This confirms practical table reuse/adaptation, but the session's homebrew changes must not be treated as source canon.

## Rights conclusion

The current 3rd Edition is explicitly advertised by the Basic Fantasy Project as CC BY-SA. The exact licence version and asset-level credits should be read in the current PDF before release. Avoid deriving the DMOS template from old OGL-edition text and then labeling it as a 3rd-edition CC adaptation.
