# Monkey Isle - Current-edition canon register

Target source: current **3rd Edition**.

## Hard canon currently confirmed from current publisher/project metadata

- `Monkey Isle` is an adventure module/setting by J. D. Neal for Basic Fantasy RPG.
- It is intended for characters of levels 4-6.
- The main environment is a lush green island in a broad blue ocean.
- The island contains ancient beasts, strange creatures and scattered ancient ruins.
- The module contains an island map.
- It contains multiple adventure locations in both wilderness and dungeon form.
- It contains an extensive section of new monsters.
- Current 3rd Edition is CC BY-SA and explicitly OGL-free.

## Sandbox identity

Current metadata plus historical source/review context consistently presents Monkey Isle as a reusable island setting rather than a single one-way plot. Until the 3rd Edition text is extracted, DMOS should model `revisitable sandbox` as a design expectation but not import individual old-edition locations, NPCs or scenarios as current canon.
