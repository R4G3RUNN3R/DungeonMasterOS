## Online fallback policy

If a required core book is not owned/identified locally:

- prefer official SRD/Creative Commons/ORC/OGL/open rules
- use official publisher rules/errata/FAQ/free rules
- use licensed providers
- use reputable secondary references only for corroboration

Do not bypass paywalls or use unauthorized/cracked copies.

The implementation goal is complete mechanical support, not acquisition of unauthorized sourcebook copies.
